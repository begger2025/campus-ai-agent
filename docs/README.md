# 文档导航

本目录按"当前有效 / 正式交付 / 设计 / 实验 / 归档"分层组织。**判断某份文档是否代表项目当前状态，以所在目录为准**：根目录与 `coursework/` 是当前有效，`archive/` 是历史记录。

## 当前有效的参考文档（根目录）

| 文档 | 内容 |
|------|------|
| `architecture.md` | 系统架构 |
| `database.md` | 数据库设计 |
| `api.md` | 接口文档 |
| `data-sources.md` | 数据来源说明 |
| `field-spec.md` | 采集字段规范 |
| `page-responsibilities.md` | 前端页面职责划分 |

| `deploy-runbook.md` | 公网部署操作手册 |
| `crawl-runbook.md` | 多平台采集手册 |
| `demo-guide.md` | 演示动线指引 |

## 子目录

| 目录 | 内容 | 是否代表当前状态 |
|------|------|:---:|
| `coursework/` | **软件工程课程 9 份正式交付物**（需求/建模/架构/工程化/测试/配运维/团队/视频脚本 + 缺陷台账） | ✅ 是 |
| `design/` | 功能设计文档（事件聚类精修、生命周期、时效、风险、选题、证据核验） | ✅ 是 |

| `data/` | 评测基准结果 JSON（对话质量各轮次留档） | ✅ 是 |
| `archive/` | **开发过程历史记录**（周迭代、爬取交接、早期方案等） | ⚠️ 历史快照，见下 |

## 关于 archive/

`archive/` 收录开发过程中的阶段性文档（周迭代记录、爬取诊断/交接、早期共享 MySQL 方案、协作指南等）。**这些是历史快照，反映的是当时的状态，可能与项目当前实现不一致**——项目的当前状态一律以根目录参考文档、`coursework/` 交付物和实际代码为准。保留归档是为了追溯项目演化过程，不作为当前依据。
