# 爬虫异常记录（任务 5）

记录第一周采集过程中遇到的实际问题，便于组内复盘与后端/Agent 同学理解数据质量。

---

## 记录表

| 编号 | 平台 | 现象 | 原因分析 | 当前处理 | 后续建议 |
|------|------|------|----------|----------|----------|
| E01 | 微博 | API 第 1 页返回 **432 Client Error** | 未登录 / 反爬策略，m.weibo.cn 接口拒绝请求 | 改试 Playwright；仍失败则走备用源 | 登录 Cookie、降低频率、换官方/合规数据源 |
| E02 | 微博 | Playwright 补充采集 **0 条** | 搜索页需登录或 DOM 结构变化 / 无头浏览器被识别 | 记入日志，不阻塞流程 | 维护选择器；必要时人工导出样本 |
| E03 | 贴吧 | 请求 **Read timed out (30s)** | 网络慢或贴吧反爬、连接被挂起 | 超时后跳过，依赖微博或 demo 补充 | 增加重试；代理；换版块 URL |
| E04 | 贴吧 | 列表页能打开但 **详情页 404**（潜在） | 帖子删除、权限变更、URL 规则变化 | 第一周仅采列表页字段，详情 URL 作引用 | 采集时校验 HTTP 状态，404 不入库 |
| E05 | 贴吧 | **只能抓到标题，正文为空或极短** | 列表页 HTML 不含正文，需进详情页 | `content` 用「回复数摘要」代替正文 | 详情页二次抓取 |
| E06 | 全平台 | 真实采集 **0 条** 时自动 **demo 补充** | 主备源均失败 | `meta.mode=live+demo_fallback`，保证 20+ 条联调 | 答辩时说明为结构化样本，非实时爬取 |
| E07 | 导入 | `import_posts` 显示 **imported 0** | 相同 `url` 已存在于 `raw_posts`（重复导入） | 视为成功，数据已在库 | 按 `id` 去重或提供 `--force` 选项 |
| E08 | 数据 | **个人信息误采集风险** | 公开帖可能含昵称、联系方式 | 第一周仅用公开列表；不采私信；样本为校园议题 | 入库前过滤手机号/学号模式 |
